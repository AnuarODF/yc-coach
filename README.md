# YC-Коуч — жёсткий фокус-коуч фаундера для Claude Code

Персональный ИИ-коуч по методологии Y Combinator: держит тебя на **одной метрике**, ведёт дейли и недельные разборы, помнит твой прогресс между сессиями. Не чирлидер — режет распыление, vanity-метрики и самообман сократовскими вопросами.

## Что умеет

- **Дейли** (2–5 минут): цель этапа и метрика → вчерашняя «лягушка» → одна главная задача дня → что сегодня НЕ делаем → блокеры.
- **Недельный разбор**: PPP (Progress / Problems / Plans) → Default Alive/Dead → счётчик живых разговоров с клиентами → пересборка цели через GROW.
- **Первая сессия**: интервью о твоём стартапе + постановка цели этапа и North Star метрики через GROW.
- **Память**: состояние живёт в файле `YC-Коуч — Состояние.md` в твоём Obsidian vault (или папке проекта) — коуч читает его в начале и перезаписывает в конце каждой сессии.

В основе — эссе Пола Грэма и YC Startup Library: make something people want · talk to users · do things that don't scale · default alive/dead · одна North Star метрика. База знаний лежит в `references/yc-method.md` со ссылками на первоисточники.

## Установка

```bash
npx skills add AnuarODF/yc-coach
```

## Как пользоваться

1. Запусти `claude` из папки своего Obsidian vault (так коуч найдёт свою память).
2. Напиши **«дейли»** — утренний ритуал, или **«неделя»** — недельный разбор.
3. В первый раз коуч сам создаст файл памяти и проведёт интервью о твоём стартапе.
4. Заканчивай сессию словом «всё» — коуч сохранит состояние.

## Стартовый набор для новичка в Claude Code

Ставишь Claude Code недавно? Вместе с коучем пригодятся (каждый скил — одна команда, все бесплатные):

```bash
# Документы Word / Excel / PDF / PowerPoint — официальные скилы Anthropic
npx skills add anthropics/skills

# Obsidian: Claude работает с твоим вторым мозгом
# (после установки попроси Claude поправить путь к твоему vault)
npx skills add https://github.com/mattpocock/skills --skill obsidian-vault

# Поиск и установка новых скилов под любую задачу
npx skills add https://github.com/vercel-labs/skills --skill find-skills

# Живые тексты без AI-штампов (письма, посты, тендеры)
npx skills add blader/humanizer

# Финансовый советник собственника: кэш, найм, прогнозы
npx skills add EveryInc/charlie-cfo-skill
```

Проверка: после установки напиши в Claude Code «какие скилы у меня установлены и что они умеют».
